# data

`snapshot_2026-09-11_php_top100.csv` — top 100 coins by market cap, priced in
Philippine pesos, generated by `gecko_snapshot.py` on 11 September 2026.

Committed as a worked example and as the dataset referenced in the project
README. Regenerate with:

    python gecko_snapshot.py --vs-currency php --per-page 100 \
        --out data/snapshot_2026-09-11_php_top100.csv
